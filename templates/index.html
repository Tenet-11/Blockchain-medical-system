Hybrid Blockchain Demo

Medical Record Integrity System

SQLite off-chain storage + Hash verification + Patient history on blockchain

Doctor Mode Can add, query, and verify medical records.

新增病歷

Doctor / Admin 可新增一筆醫療紀錄。若 patient_id 相同，也可以視為同一病患的新就診紀錄。

更新病歷版本

不是覆蓋舊資料，而是用同一個 Patient ID 新增一筆新的 Record，讓區塊鏈保留病患從過去到現在的歷史。

查詢病患完整病歷

輸入 Patient ID，查詢該病患從過去到現在的所有區塊鏈病歷紀錄。

查詢單筆病歷

Doctor / Admin 可查任一筆；Patient 只能查自己的病歷。

驗證病歷

重新計算 hash，判斷資料是否被竄改。

模擬竄改

Admin demo 功能：將 diagnosis 改成 Cancer，但不更新原始 hash。

恢復資料

Admin 可將被竄改的病歷恢復成 blockchain 中保存的原始狀態。

刪除資料

Admin 可刪除指定 record_id 的病歷資料。
